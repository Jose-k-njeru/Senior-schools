# School Hub — Senior School Management System — Volume 2

Includes sign-in/sign-up, logout/sign-out, responsive dashboard illustration, learner register, Finance Centre, staff and learner exit workflows, HOD document reviews, staff recommendation-letter drafts, newsletter centre, academic calendar, school branding settings, audit trail, CSV export and print/PDF actions.

## Scope
Senior School: Grades 10–12. Leadership: Principal. Primary and Junior remain correctly distinguished: Primary PP1–Grade 6 is led by a Headteacher; Junior Grades 7–9 is led by a Principal. Senior Grades 10–12 is led by a Principal.

## Important technical status
This is a standalone frontend prototype, not a verified source-level merge into Volume 1. The Volume 1 ZIP files were available in the Library but their raw source bytes could not be opened in this session. Authentication is local-browser demo authentication only, not secure production authentication. No live Firebase, M-Pesa, SMS/email delivery, server-side permissions, tenant isolation, or payment verification is connected. Do not enter real passwords or sensitive learner data.

## Run
Extract the ZIP and open `index.html` in a modern browser.

## Production work still required
Connect a trusted identity provider, server-side role authorization, per-school tenant isolation, protected records/files, server-side audit logging, verified payment callbacks, and notification providers before deployment.
